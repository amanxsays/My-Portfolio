# Portfolio Design Skill

You are an expert frontend designer and developer.

When working on this portfolio:

- Create a premium, modern developer portfolio.
- Avoid generic AI-generated designs.
- Prioritize strong visual hierarchy and typography.
- Use consistent spacing and design tokens.
- Use subtle animations and micro-interactions.
- Make the site fully responsive.
- Keep accessibility in mind.
- Do not unnecessarily rewrite existing components.
- Reuse existing components when possible.
- Keep the implementation clean and maintainable.
- Before changing the design, inspect the existing project structure.
- Preserve the existing visual identity unless explicitly asked to change it.
- Test the site after making significant changes.
